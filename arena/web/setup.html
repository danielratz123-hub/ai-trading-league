Setup

Follow the steps from top to bottom.

← Dashboard

The setup page only works on the computer that runs the league. Open it there (double-click start.cmd) to change settings.

1

Connect market data (Alpaca)

The league uses real US stock prices from Alpaca. It's free and uses no real money.

  1. Create a free account at alpaca.markets.
  2. Open the Paper Trading dashboard and press API Keys → Generate New Keys.
  3. Paste both keys below and press Save & test.
2

Connect the two AIs

Both AIs play on your own subscriptions (Claude Pro/Max and ChatGPT Plus/Pro), so there are no API bills. They run through the official apps Claude Code and Codex.

Installing needs Node.js (LTS).

Choose the models

For a fair match, pick models of a similar level:

Both AIs answer one tiny question through the league's tools (uses a little of each plan).
3

Download market data

Downloads daily prices for the S&P 500 and major ETFs since 2015. The first time takes a few minutes.

4

Start the league

Gives each AI $1,000 of virtual money and lets them make their first decisions. Each AI researches for a few minutes, so this takes a while. Best on a weekend; mid-week it starts from last week's close.

Try a practice week first (optional)

Replays past weeks with the real AIs in a separate practice database. Your real league isn't touched. Web search is off, since the AIs could otherwise look up what happened next.

5

Keep it running

The scheduler runs the league automatically on US market time: trades at 9:50 each trading morning, checks after each close, and the AIs decide every Saturday. It runs while this app is open, so keep the black start.cmd window open and the computer awake (Settings → System → Power → sleep: Never).

6

Show it in Alpaca (optional)

The league trades virtual $1,000 accounts inside this program. To also watch the AIs in Alpaca, each AI's portfolio can be copied into a paper account (no real money) after every trading morning. The copy holds the same percentages, scaled to the paper account's size. Shorts are rounded down to whole shares.

  1. In Alpaca, open the account menu (top left) and choose Open New Paper Account.
  2. Switch to that new paper account and press API Keys, Generate New Keys.
  3. Paste them below for ChatGPT. Claude uses the keys from step 1, unless you fill its own below.
