Agents

Work at the same time
Different agents can work at once, one task each. Extra runs also wait while the server is busy, so the league always has room.
Each agent's default model and effort. A task can still pick its own model.
To add another agent, install its CLI in Dockerfile.hub and add it to hub/agents.yaml, then sign it in once on the server. HUB.md, "Add an agent", has the steps.
